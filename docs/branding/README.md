# KSL brand assets

The KSL logo is a **discrete-event timeline monogram**: the wordmark **KSL** over a
left-to-right time axis (an arrow of time), with amber **event arcs** that overlap at
staggered heights to signify concurrent discrete events.

## Files

| File | Use |
|------|-----|
| `ksl-logo.svg` | Primary mark (light backgrounds). The default everywhere. |
| `ksl-logo-reversed.svg` | Primary mark for dark / photographic backgrounds. |
| `ksl-logo-expanded.svg` | Labeled (t1…t5) mark — large formats only (banners, slides, print). |
| `ksl-mark.svg` | Icon only, no letters — avatars and favicons. |
| `ksl-social-card.png` | 1280×640 — upload under GitHub Settings → General → Social preview. |
| `brand-sheet.html` | Open in a browser to preview every variant and download PNGs (banner, avatar, favicon, social card) at exact sizes. |

## Palette

| Color | Hex | Role |
|-------|-----|------|
| KSL Indigo | `#4338CA` | Primary ink |
| KSL Indigo Light | `#C7D2FE` | Reversed ink (on dark) |
| KSL Amber | `#F59E0B` | Events / accent |
| KSL Deep Indigo | `#1E1B4B` | Banner / avatar background |
| Ink / Navy | `#0F172A` | Dark surfaces |
| Paper | `#FFFFFF` | Light background |

## Usage

- The **primary** mark is the default and the only version below ~200px wide (avatars,
  favicons, inline). The **expanded** (labeled) mark is for large formats only.
- Keep clear space of at least the cap-height of the "K" around the mark.
- Don't recolor the amber, stretch the mark, add shadows/gradients, or use the labeled
  version at small sizes.
- For final print production, convert the "KSL" wordmark text to outlines so it renders
  identically on machines without Helvetica/Arial.
