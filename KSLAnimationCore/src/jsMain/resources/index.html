KSL animation in the browser

Each player below replays a real .atf trace produced by a KSL run, through the same replay engine and playback clock the desktop viewer uses, compiled to JavaScript. No server is involved — the traces are static files.

Discrete-event: an annotated clinic

A queue of patients and one nurse. Watch the queue fill while the nurse is busy (red) and drain when idle (green). Scrub to any point; drag to pan; scroll to zoom; double-click to reset the view.

Agent-based: flocking

Eighty boids in a continuous space, from a 20,000-event trace. The trace is served gzipped and decoded in the browser; parsing is chunked, so the progress line moves instead of the page freezing.

Embedding one

This is the whole integration — no JavaScript of your own:

<div data-ksl-trace="traces/pharmacy.atf.gz"
     data-ksl-layout="traces/pharmacy.lay.json"
     style="height:480px"></div>
<script src="ksl-animation.js"></script>
